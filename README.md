A fast pure-JavaScript static site generator. It parses front matter, renders the template language with includes, converts Markdown bodies to HTML, and emits index, tag, and paginated archive pages, running 1.31 to 1.41 times faster than the baseline on the practice set.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
